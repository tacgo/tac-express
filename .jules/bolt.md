## 2025-02-18 - Missing array map memoization in Table components
**Learning:** React Server Components fetching data on the client (using React Query via hooks like `useShipments`) return new array references or fallback defaults like `[]` on every render. If this data is immediately mapped (e.g. `data.map(toRow)`) and passed to deeply nested TanStack tables or composed UI primitives, it breaks referential equality and forces expensive re-renders and table state resets on every React cycle.
**Action:** When transforming raw API data into presentation props for composed React views, always wrap the transformation in a `React.useMemo` (e.g., `React.useMemo(() => (data ?? []).map(...), [data])`). Avoid using default parameter destructuring (like `const { data = [] } = useQuery()`) because it assigns a fresh unstable array on every render during loading/error states.
