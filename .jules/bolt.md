## 2024-05-24 - Unstable query data references breaking child component rendering
**Learning:** Destructuring with an inline default array (e.g., `const { data = [] } = useQuery(...)`) inside a React component creates a new array reference on every single render during the query's loading state (`data` is `undefined`). When this unstable reference is then passed to a `.map()` transformation and subsequently to complex list/table child components, it causes severe unnecessary re-rendering across the entire child tree even when no actual data has changed.
**Action:** When using `useQuery` or similar hooks, destructure the raw value without an inline default. Apply the fallback inline within a `React.useMemo` block that wraps any subsequent data transformations (e.g., `React.useMemo(() => (data ?? []).map(...), [data])`) to preserve referential equality when the underlying data hasn't changed.
