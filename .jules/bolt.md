## 2024-05-18 - Prevent Array recreation in Query Hooks
**Learning:** Using default parameter destructuring for array results in TanStack Query (e.g. `const { data = [] } = useQuery()`) causes a new array reference to be created on *every render* when `data` is undefined (like during initial fetch). Passing this mapped array directly to the generic `DataTable` component forces a deep re-render of the entire table on every background refetch, hurting performance.
**Action:** When memoizing array mappings from query hooks, always avoid default parameter destructuring. Instead, retain the query object and use nullish coalescing inside a `React.useMemo` (e.g., `const rows = React.useMemo(() => (query.data ?? []).map(toRow), [query.data])`). This ensures stable reference for tabular components like `DataTable`.
