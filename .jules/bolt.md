## 2024-08-28 - Avoid inline map on undefined arrays breaking React.useMemo
**Learning:** When using TanStack query and destructuring `data = []` (or mapping the data inline directly `const rows = (query.data ?? []).map(toRow)`), the mapping runs on every render when `query.data` changes or is undefined initially. Since the table components that receive `rows` use structural equality, providing a newly allocated array on every render breaks memoization (like in `DataTable`), triggering unnecessary expensive sub-tree re-renders for data surfaces that don't need to re-render.
**Action:** When memoizing array mappings from query hooks, avoid destructuring with a default empty array. Instead, retain the query object and use nullish coalescing inside `React.useMemo` (e.g., `const rows = React.useMemo(() => (query.data ?? []).map(toRow), [query.data])`) to provide a stable reference and avoid breaking table memoization.
