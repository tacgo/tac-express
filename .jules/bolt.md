## 2024-05-15 - Unmemoized Query Data Array Destructuring Causes Deep Re-renders
**Learning:** Destructuring query hook results with a default empty array fallback (e.g. `const { data = [] } = useQuery()`) without memoization causes the parent component to allocate a new empty array reference on every render when the data is undefined (like during initial fetch). If this unmemoized array is then mapped and passed to a child component (like a DataTable), it triggers expensive deep re-renders down the React component tree even when the actual underlying data hasn't changed.
**Action:** Always wrap array mappings derived from query hooks in `React.useMemo` (e.g. `const rows = React.useMemo(() => (query.data ?? []).map(toRow), [query.data])`) to ensure stable references are passed to child components. Avoid destructuring the data property with a default fallback if it will be used in a memoization dependency array.
