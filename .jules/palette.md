## 2024-05-24 - Premium focus signals
**Learning:** Found multiple instances across the dashboard and marketing sites where interactive elements (native `<button>`, complex primitives, tracking inputs) were missing focus indicators entirely or using outdated standard Tailwind rings (like `focus-visible:ring-1 focus-visible:ring-ring`). This created inconsistent keyboard navigation experiences compared to the core form elements that utilize the new premium focus treatment.
**Action:** Applied `focus-visible:outline-none focus-visible:tac-focus-premium` systematically to interactive elements across marketing Nav, TrackingWidget, FileDropzone removal buttons, ErrorBoundary resets, and the composed NotificationBell. Ensured native `<button>` and `<input>` elements receive the proper primary bloom focus ring.
