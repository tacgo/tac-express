## 2024-11-02 - Premium Focus Signals for Native Elements
**Learning:** In the TAC Express design system (Violet Grid), native HTML elements (`<button>`, `<input>`, `<a>`, `<Link>`) do not automatically inherit the custom `tac-focus-premium` focus ring bloom that is built into design system primitives. Relying on default focus outlines or generic Tailwind ring classes (`ring-1 ring-ring`) creates an inconsistent keyboard navigation experience and violates the premium UI quality rubric.
**Action:** Always manually apply `focus-visible:outline-none focus-visible:tac-focus-premium` to any interactive native element (especially custom triggers, navigation links, and unstyled inputs) to ensure they share the same brutalist 1px outline and 8px primary bloom as standard components.
