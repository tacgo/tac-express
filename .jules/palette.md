## 2024-08-28 - Unified Focus Rings
**Learning:** Found older `focus-visible:ring-ring` being used manually on some composed elements (`notification-bell.tsx`, `stat-card.tsx`, `v7-ops-finance.tsx`) instead of the standard `focus-visible:tac-focus-premium` class defined in globals.css. This causes inconsistent focus rings across interactive elements. Also, the `<button>` inside `notification-bell.tsx` for Radix asChild uses generic `hover:bg-muted/50` and is missing the `focus-visible:outline-none focus-visible:tac-focus-premium` for proper keyboard accessibility.
**Action:** Replace manual `ring-ring` usages with `tac-focus-premium` to ensure a consistent, accessible focus state across the app. Add `tac-focus-premium` to any interactive elements lacking proper keyboard focus.
